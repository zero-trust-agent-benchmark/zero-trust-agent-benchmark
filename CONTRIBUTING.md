# Contributing

1. Use Python 3.12.
2. Create a virtual environment: `python -m venv .venv`.
3. Install development dependencies: `python -m pip install -e ".[dev]"`.
4. Run `bash scripts/check.sh` before sending changes.
5. Keep the frozen Zero Trust Agent Benchmark contract stable: trace JSON shape, defense
   request/response, CLI names, and Python API.

By contributing, you certify the Developer Certificate of Origin sign-off in
your commits.
